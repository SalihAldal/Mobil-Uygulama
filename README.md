# Mini Katalog Uygulamasi

Flutter ile gelistirilmis temel seviye bir katalog uygulamasi. Liste, detay
sayfasi, arama ve sepet simulesi icerir.

## Kullanilan Flutter Surumu
- Flutter SDK (3.22+ onerilir)

## Kurulum ve Calistirma Adimlari
1. Flutter SDK kurulu oldugundan emin olun.
2. Eger platform klasorleri yoksa proje kokunde su komutu calistirin:
   `flutter create .`
3. Bagimliliklari yukleyin:
   `flutter pub get`
4. Emulator acin veya cihazi USB ile baglayin.
5. Uygulamayi calistirin:
   `flutter run`

## Ekranlar
- Ana sayfa (banner + arama + grid)
- Urun detayi
